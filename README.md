# Agora

A Agora-inspired web application where users can share posts, explore communities, and interact with other users.  

Users can browse content and engage in discussions on various topics.  

The project aims to give a user space where they can share their thoughts , photos , opinions and suggestions.

Users can create a room with their friends related to a specific topic and talk with each other for a specific interval of the time.

Designed to provide a smooth and interactive social media experience.
